# gogenfilter golangci-lint plugin

A [golangci-lint v2 module plugin](https://golangci-lint.run/plugins/module-plugins/) that detects auto-generated Go files using [gogenfilter](https://github.com/LarsArtmann/gogenfilter).

## What it does

The plugin runs gogenfilter's detection on every Go file passed to the analyzer and reports a diagnostic for each file classified as auto-generated. The diagnostic names the detected generator (sqlc, templ, protobuf, mockgen, etc.).

This fills a gap in golangci-lint's built-in generated-file handling, which relies on filename conventions and the generic `// Code generated ... DO NOT EDIT.` pattern. Gogenfilter adds:

- **18 specific generator detectors** (sqlc, templ, protobuf, go-enum, mockgen, wire, deepcopy-gen, etc.)
- **Config-aware SQLC detection** (classifies `models.go` in sqlc output dirs without relying on header comments)
- **Content-based detection** (catches generated files with non-standard names)

## Installation

### 1. Create a `.custom-gcl.yml`

```yaml
version: v2.4.0
plugins:
  - module: 'github.com/LarsArtmann/gogenfilter/plugin'
    import: 'github.com/LarsArtmann/gogenfilter/plugin'
    version: v0.1.0
```

### 2. Build the custom binary

```sh
golangci-lint custom -v
```

### 3. Configure in `.golangci.yml`

```yaml
version: "2"
linters:
  default: none
  enable:
    - gogenfilter
  settings:
    custom:
      gogenfilter:
        type: module
        description: "Detect auto-generated Go files"
        settings:
          generators:
            - sqlc
            - templ
          exclude-paths:
            - vendor/**
            - "**/testdata/**"
```

### 4. Run

```sh
./custom-gcl run ./...
```

## Configuration

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `generators` | `[]string` | all | Restrict detection to specific generators (e.g., `sqlc`, `templ`, `protobuf`) |
| `exclude-paths` | `[]string` | none | Glob patterns to exclude from detection |

## Diagnostic

The plugin reports one diagnostic per detected generated file:

```
main.go:1:1: file is auto-generated by sqlc — consider excluding from linting (generated)
```

Use golangci-lint's `issues.exclude-rules` to suppress diagnostics for files you've already handled.
